# Happy Friendship Day with Rich

A simple Python script that prints a colorful "Happy Friendship Day!" message in the terminal using the Rich library.

## Installation

```bash
pip install -r requirements.txt
```

Or install Rich directly:

```bash
pip install rich
```
## Concepts Learned

* Working with third-party Python packages
* Terminal text styling
* Applying colors to individual characters
* Using Rich's Console and Text classes

## Library Used

* Rich

## Run the Script

```bash
python friendship_day.py
```

## Expected Output

A colorful "Happy Friendship Day!" message displayed in the terminal, with each character rendered in a different color.
